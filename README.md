# WARP-NAV 9X

자동차 주행 경로를 **초광속 우주선의 워프 항해**로 보여 주는 장난감 내비게이션 웹앱입니다.
지도는 없습니다. 직진 구간은 워프 줄기가 흐르고, 회전·경유 지점에서는 워프 아웃하여 천체가 나타납니다.
화면은 90년대 디지털 계기판 느낌의 HUD입니다.

- 배포: GitHub Pages (`index.html` 한 파일, 외부 라이브러리 없음, 캔버스 2D)
- 환산: **1 km/h = 광속 1배**, **1 km = 1,000 광년**
- 언어: **한국어 / English** 중 하나를 고를 수 있습니다(CONFIG의 버튼 줄 바로 아래, 선택은 저장됨). 선택한 언어 하나로만 표시합니다. 계기 약어(WARP·IMPULSE·TURN·ARRIVED·REROUTE, THR, AUTO, ENERGY, G-FIELD, SHLD/DFLT/CORE, MACH, C, LY)는 두 언어 모두 영문 그대로입니다.
- 알림: 지도 길 안내가 아닌 연출용 앱입니다. 실제 운전 중에는 안전 운전이 우선입니다.

> 이 문서는 기능을 추가하거나 버그를 고칠 때마다 함께 갱신합니다. 맨 아래 [변경 이력](#변경-이력)을 참고하세요.

## 모드

### SIM 시뮬레이션
- **임의 경로**: 총 항로 길이(3~300 km)와 **워프 아웃 횟수(중간 지점 + 목적지)**를 지정합니다. 횟수 N이면 중간 지점 N−1개를 거의 균등하게 배치하고 목적지가 마지막 1회입니다(항로 막대의 가로 눈금 N−1개 + 빨간 목적지 표시). 길이에 비해 너무 많으면 구간당 최소 약 0.4 km가 되도록 줄이며, 입력칸 아래에 가능한 최대 횟수가 표시됩니다. "임의" 체크 시 자동으로 정합니다.
- **목적지 지정**: 출발지(비우면 현재 위치)와 목적지를 검색해 실제 도로 경로(OSRM)로 시뮬레이션합니다.
- **스로틀 레버**와 **AUTO**로 속도를 조절하고, 시간 배율을 고를 수 있습니다.

### GPS 실주행
- 현재 위치에서 목적지까지 실제 주행 경로를 계산해 따라갑니다. 최근 목적지 5개를 기억합니다.
- **GPS 신호 대기**: 위치를 받기 전에는 대기 모드로 두고, 수신되면 자동으로 경로를 만듭니다.
- **경로 이탈 시 재탐색**, **GPS 신호 소실 시 추측 항법**으로 계속 진행합니다.
- **화면 꺼짐 방지**(Wake Lock)를 사용합니다.
- 나침반은 GPS 진행 방향 또는 경로 방위를 실제 방향으로 표시합니다.

## 화면 구성과 연출

- **속도 표시**: 큰 7-세그먼트 숫자 위에 MACH / C 단위(속도 라벨과 같은 줄). 단위는 MACH / C 두 가지입니다. 워프(약 30 km/h 이상)에 들어가면 C가 밝아집니다. 워프는 속도 35 km/h 이상에서 켜지고 28 km/h 미만 또는 회전 직전에 풀립니다.
- **남은 거리**(광년)와 **ETA**는 7-세그먼트 숫자이며 화면 오른쪽 위, 다음 기동과 같은 높이에 붙어 있습니다(항로 막대는 그 아래에서 시작). 다음 기동·이어지는 기동의 남은 거리도 7-세그먼트입니다. 다음 기동 글이 길어 잔여 거리 쪽을 넘게 되면 고정 폭 안에서 좌우로 천천히 오가며 전체를 보여줍니다. 하단에는 속도 숫자·ENERGY/G-FIELD·큰 나침반(지름이 종료 버튼 폭과 같음)이 놓입니다. 그 밖에 항로 막대, 스타데이트가 있습니다.
- **워프 줄기**: 직진 구간에서 별이 중심에서 퍼집니다. 도로가 굽으면 별이 좌·우로 치우쳐 흐릅니다(굽이 감지).
- **회전·경유 지점**: 워프 아웃 후 천체가 나타나며 시선이 회전합니다.
- **스쳐 지나가는 천체(flyby)**: 직진 구간에서 가끔 항로 옆을 지나갑니다. 속도에 비례해 지나가고 옆으로 충분히 떨어져 있습니다.
- **다른 우주선**: 소·중·대·특대형, 같은 방향(앞지르기) 또는 엇갈림. 후미에 빛줄기가 있습니다. 한 대 또는 무리(최대 10대까지)로 나타납니다.
- **메시지 박스** (색·점등 속도는 CONFIG에서 변경)
  - GPS 신호 소실: 빨강, 빠른 점등
  - 경로 변경: 주황, 점등 없음
  - 정차(3초 이상): 초록, 느린 점등, 문구가 랜덤으로 바뀜
  - 도착 직전 / 출발(목적지 지정 후 첫 이동 때만)
- **종료 버튼**: LCD 스타일, 두 번 눌러 종료합니다.

### 등장 천체 (44종)
행성(지구형 6, 불모 5, 가스 6, 도시 4, 기계 3), 항성 7, 블랙홀 1, 펄서 2, 퀘이사 2, 은하 3, 성운 3, 소행성대 2.
일부 행성에는 토성형 고리, 궤도 정거장, **SF 궤도환**, **궤도 엘리베이터**가 있습니다. 모두 코드로 생성하는 절차적 그래픽입니다.

### 그래픽 방식
- 우주선·정거장: 3D 다각형 모델을 원근 투영으로 그립니다(진짜 3D).
- 행성류: 평면 질감을 구에 감아 자전·명암·대기를 입히는 의사(疑似) 3D.
- 궤도환·엘리베이터·은하·성운·퀘이사·블랙홀·펄서: 2D 합성 효과.

## CONFIG (설정)
맨 위: 슬라이드 전체 리셋 / 메시지 설정 전체 리셋 / 닫기. 박스 바깥을 눌러도 닫힙니다. 초기 화면 우측 위 CONFIG 버튼으로도 들어갈 수 있습니다.

| 항목 | 범위 | 기본값 |
|---|---|---|
| 천체 통과 속도 | ×0.5 ~ ×3 | ×1 |
| 워프 줄기 길이 | ×0.1 ~ ×3 | ×1 |
| 천체 통과 빈도 | ×0 ~ ×3 (기준 16~42초 ÷ 배율) | ×1 |
| 다른 우주선 무리 빈도 | ×0 ~ ×3 (기준 9~27초 ÷ 배율, ×3에서 3~9초) | ×0.75 (12~36초) |
| 무리당 최대 우주선 수 | 1 ~ 10대 | 6대 |
| 다른 우주선 속도 | ×0.5 ~ ×3 | ×1 |
| 메시지별 표시 / 색(초록·주황·빨강) / 점등 속도 | | 항목별 기본값 |
| 등장 천체 목록 (맨 아래, 접기/펼치기) | 천체별 체크, 그룹별 ON/OFF, ALL ON/OFF | 전체 ON |

- **실험 기능 (맨 아래, LAB)**: ① 행성·항성 3D 표시(WebGL) ② 성능 표시 ③ 디버그 모드(아래). 기본값은 모두 꺼짐이며 CONFIG 초기화로 바뀌지 않습니다.
- 3D 표시: 블랙홀은 강착원반과 렌즈 아치를 셰이더로 연속해서 그립니다(2D의 조각난 호 문제 해결). 행성(지구형·암석·가스·도시·기계)과 항성(표면 텍스처 있는 별)은 **구 부분**만 WebGL로 그립니다(삼각형 2,304개 구 + 기존 절차적 텍스처, 조명·구름·도시 불빛·대기 테두리는 셰이더). 고리·정거장·궤도환·엘리베이터·코로나·홍염은 기존 2D 그대로 위에 얹으므로 모양과 겹침 순서가 같습니다. WebGL을 쓸 수 없거나 오류가 나면 자동으로 2D로 그립니다.
- 디버그 모드(기본 꺼짐): 경유지·목적지·스쳐 지나가는 천체 아래에 이름, 종류, 구성(위성·고리·정거장 형태·궤도환·엘리베이터·야간조명·다이슨 스웜 등), 어두운 면 비율, 시드를 표시하고, 다른 우주선 아래에는 크기 등급·형태·진행 방향·길이·거리·속도·엔진/면 수를 표시합니다. 평소의 스쳐 가는 천체 이름 표시는 그대로이고, 디버그 모드에서만 위 정보로 바뀝니다.
- 성능 표시: 화면 중앙에 작은 창(눌러서 초기화). ALL=전체 프레임, BODY=천체(행성·항성)가 그려진 프레임의 fps, 프레임 간격 평균/상위 5%/최대(ms), JS 처리 시간, 천체 그리기 CPU 시간, 3D 켜짐 여부, 텍스처 업로드 시간. 같은 조건에서 3D를 켜고 끄며 BODY 줄을 비교하세요.
- 슬라이더는 설정 화면 오른쪽 2/3에만 있어서, 스크롤하다 실수로 값이 바뀌지 않습니다.
- 등장 천체를 전부 끄면 전체가 등장합니다. 항로 천체는 경로를 시작할 때 정해지므로 새로 출발해야 반영됩니다.
- 설정과 초기 화면 값(탭, 경로 종류, 길이, 중간 지점, 시간 배율)은 브라우저에 저장됩니다. 출발지·목적지 입력은 저장하지 않습니다.

## 다른 우주선 등장 규칙
1. "우주선 무리 빈도"로 다음 무리 시점 T를 정합니다(기준 9~27초 ÷ 배율).
2. 그 무리의 대수는 1~10대 중에서 3:3:2:2:1:1:1:1:1:1 비율로 뽑습니다. 최대 대수를 낮추면 그 범위 안에서 같은 비율로 뽑습니다.
3. 각 우주선은 T의 40~160% 시점에 따로 나타납니다. 화면에 동시에 12대를 넘으면 건너뜁니다.
3-1. **간격 확보**: 새 우주선은 우리 우주선과, 그리고 이미 있는 모든 우주선(진행 방향과 무관)과 선체 크기만큼 떨어진 항로에만 나타납니다. 빈 자리가 없으면 바깥쪽으로 넓혀 가며 찾고, 그래도 없으면 그 우주선은 나오지 않습니다.
4. 대형·특대형은 엇갈림 : 같은 방향이 3 : 1입니다. 엇갈림은 같은 방향보다 훨씬 빠르게 지나갑니다.
5. 같은 방향 우주선은 소실점 쪽으로 70% 진행하면 희미해지기 시작해 90%에서 투명해집니다. 엇갈린 우주선은 빛꼬리가 화면을 벗어난 뒤에 사라집니다.
6. **회전·경유 주변 규칙(천체가 화면에 나타나는 순간 기준)**: 회전·경유 천체가 화면에 나타나기 시작한 뒤(목표 0.4 km 전부터) 새로 나오는 우주선은 천체와 우리 우주선에서 아주 멀리서 시작합니다. 그 시점에 이미 있던 우주선은 어두워지거나 사라지지 않고 그대로 움직입니다. 여기서 "멀리"는 진행 방향(z)이 아니라 항로 중심에서 옆으로 떨어진 거리 √(x²+y²)입니다(화면에서 천체 반지름의 약 1.2배 밖). 회전 중에는 새 우주선이 나오지 않고, 있던 우주선은 서서히 사라집니다. 회전 직후 5초 안에 나오는 우주선도 아주 멀리서 시작합니다. 천체 스침은 회전 16초 전부터 회전 10초 후까지 나오지 않습니다(시간 배율이 높은 시뮬레이션에서는 천체가 거의 나오지 않을 수 있습니다).

## 변경 이력

> 최신이 위입니다. 날짜는 한국 시간 기준입니다.

### 2026-11-22 (18)
- 지구형 행성 구름 양·불투명도 조정: 측정해 보니 구름의 양도 적고(구름이 조금이라도 있는 면적 41%) 투과도도 높았다(합성 시 최대 78%만 덮고, 거의 불투명한 부분은 4%). 그래서 두 가지를 함께 조정했다 — 구름 문턱을 낮춰 덮인 면적을 약 51%로, 경계를 더 선명하게, 합성 불투명도를 78%→92%로. 평균 덮임(면적×불투명도)은 약 1.9배, 거의 불투명한 부분은 약 2.7배(4%→11%). 구름 각각의 크기가 아니라 덮이는 부분이 늘어난다.

### 2026-11-22 (17)
- 낮/밤 경계의 기울기: 행성 자전축이 화면에서 수직이므로, 빛이 오는 방향의 화면 성분이 수평에서 ±30° 이내가 되도록 제한했다(밤낮 경계선이 수직에서 ±30° 이내). 고리·궤도환 행성은 빛이 고리 평면 안에서 오므로 조건에 맞을 때까지 위상(밝기)을 다시 뽑는다. 엘리베이터 행성은 더 이상 케이블 방향에서 빛이 오지 않고 일반 규칙을 따른다.
- 지구형 행성 구름 개선(구름은 이전에도 있었지만 단순 노이즈였다): 위도별 기후대(적도 수렴대 ↑, 아열대 ±25° 맑은 띠, 중위도 ±50° 폭풍 경로), 도메인 워핑한 fbm 덩어리, 저기압 소용돌이(북반구 반시계·남반구 시계로 좌표를 나선으로 비틂), 경도 방향 권운 줄기. 텍스처는 256×128 → 512×256.
- 구름이 지표와 같은 속도로 돈다(이전에는 1.4배+오프셋).

### 2026-11-21 (16)
- 정거장 출입 빛무리 속도를 절반으로 줄였다(위성의 약 1/2). 이전에는 화면상 속도(px/초)가 일정해서 정거장이 행성 뒤로 돌아가 작아 보일 때 정거장 크기에 비해 빠르게 보였다(정거장 크기 .68배 vs 앞쪽 1.32배 → 약 1.9배 차이). 이제 이동 시간을 정거장의 기준 크기로 정해 속도가 정거장의 보이는 크기에 비례한다. 크기에 대한 상대 속도는 위치와 상관없이 일정하다.
- 가상 펄서: 자전축을 화면(xy) 안에 두고 수직축에서 ±30° 이내로 기울인다(시선과 수직, ζ=90°). α와 주기는 이전과 같은 규칙. 실제 펄서는 그대로다.

### 2026-11-21 (15)
